# unav_common

Shared utilities used by the other packages.

| File | Role |
| --- | --- |
| `camera_model.py` | camera projection and inverse projection |
| `occlusion_geometry.py` | world-geometry parsing and line-of-sight checks |
| `rectangular_footprint.py` | robot footprint clearance |
| `preselected_route.py` | loading and verifying the solved routes |
| `navigation_parameters.py` | validation of planner and navigation parameters |
| `capture_integrity.py`, `manifest.py` | hashes and run manifests |
